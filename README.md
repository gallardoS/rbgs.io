# rbgs.io
competitive matchmaking platform for WoW: Forever battlegrounds, featuring player ratings, match tracking, and organized wargames

## Project plan

The [canonical implementation plan and feature index](../spec.rbgs.io/PLAN.md) live in the sibling `spec.rbgs.io` checkout. Keep all new project Markdown documentation there and read its specifications before implementation; do not duplicate them in this repository. This relative link assumes the project repositories are checked out side by side.

This repository contains the web application. The backend, Windows companion, and WoW addon live in `api.rbgs.io`, `companion.rbgs.io`, and `addon.rbgs.io`. Product interfaces and development documentation are in English.
